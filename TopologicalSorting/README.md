# Topological Sorting

Study kit for topological sort / ordering problems.

## Files

- **[Guide.md](Guide.md)** — Start here. Full concept explanation, Kahn's (BFS) and
  DFS-based algorithms with Python code, complexity analysis, common problem patterns,
  and gotchas.
- **[Cheatsheet.md](Cheatsheet.md)** — One-page quick reference to glance at while
  solving problems (decision tree, mental models, common bugs).
- **[Practice_Problems.md](Practice_Problems.md)** — Curated problem list (LeetCode),
  organized into 4 tiers from foundational to advanced, with hints and a suggested
  attack order.

## Suggested workflow

1. Read `Guide.md` end to end once.
2. Keep `Cheatsheet.md` open while solving.
3. Work through `Practice_Problems.md` top to bottom, checking off boxes as you go.
4. Put your solution code in a `solutions/` subfolder here, one file per problem
   (e.g. `solutions/course_schedule_2.py`), so you can re-run and compare later.
